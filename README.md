# Luminary AI 🌟
### AI-Powered Personalised Job Interview Preparation Platform

> Built with Python • Streamlit • Groq API (LLaMA 3 70B) • Deployed Live

[🔗 Live Demo →](https://luminaryai.streamlit.app/)

---

## What it does
Luminary AI reads YOUR resume and builds a fully personalised interview experience around your actual projects and skills — not generic questions.

## 5 Modules
| Module | What it does |
|--------|-------------|
| ATS Scorer | Scores your resume against any job role with weighted keyword matching |
| Mock Interview | Resume-aware AI interviewer that never repeats questions |
| Adaptive Quiz | 7 domains, adjusts difficulty based on your accuracy |
| Performance Dashboard | Radar chart across 6 dimensions + 7-day study plan |
| Resume Enhancer | Rewrites your resume bullets for any specific job description |

## Tech Stack
Python • Streamlit • Groq API • LLaMA 3 70B • pypdf • Plotly • JavaScript (localStorage)
